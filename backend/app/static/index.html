Credibility State Taxonomy

LIKELY TRUE

Corroborated by high-authority external sources with minimal contradiction and consistent cross-modal context.

LIKELY FALSE

Directly contradicted by verified reporting or demonstrates fabricated / fabricated modal context.

MISLEADING / PARTIALLY SUPPORTED

Contains genuine factual elements embedded in false framing or non-matching imagery.

INSUFFICIENT EVIDENCE

Retrieved evidence is missing or low-relevance. Direct refusal applied to prevent ungrounded classification.
