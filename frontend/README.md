# TruthLens Frontend

## Overview
The TruthLens web interface is scheduled for full implementation in Phase 12 as defined in [DEVELOPMENT_ROADMAP.md](../docs/DEVELOPMENT_ROADMAP.md).

## Planned Technology Stack
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: React Query / SWR with local UI state
- **Core Views**:
  1. **Analyze View**: Article text, URL, headline, and image submission with multi-stage real-time progress indicators.
  2. **Results View**: Calibrated credibility assessment, confidence vs. evidence sufficiency breakdown, claim highlight spans, interactive evidence cards with provenance, and XML-guarded natural language explanations.
  3. **Research Dashboard**: Empirical benchmark comparisons, dataset statistics, interactive confusion matrices, ROC/PR curves, and ablation tables.
